## What the new boundary proves

Generation replay reconstructs the exact field, maximal order and ordered prime
base, then checks the explicitly selected Minkowski or BDF generating bound. The
completion receiver reconstructs principal relations, their presentation, compact
units and torsion in fresh objects. It recomputes the existing analytic index
with no producer workspace, cache, callback or complete flag as authority.

Write $h'$ for the relation quotient order and $U'$ for the verified unit
subgroup. The fresh analytic check bounds the positive integer
$$(h'/h)[\mathcal O_K^*:U'].$$
With a generating prime base, accepting only index one establishes both the full
class group and a fundamental unit system under the recorded hypotheses. Full
rank or successful component replay alone is not enough. Minkowski generation
does not remove the separate BF zeta-GRH assumption; the BDF route also records
its class-character GRH premise. No unconditional theorem is added here.

Only explicitly nonreusable, standard generic conditional terminal contexts take
the new resumed-map admission path. A failed live recognizer does not trigger a
general rescue. The map receives copied, freshly verified compact units and
torsion in the original field presentation. Later calls check bounded mathematical
claims and source identities rather than repeating completion or expanding units.
The context is never relabelled reusable. The ordinary live path and public
exporter's eligibility remain unchanged.
