# A guided exact modular-forms tour

This tour follows one weight-$2$ space from its old/new decomposition to an
exact Galois packet, its $q$-expansion, and arithmetic-normalized input for an
$L$-series. A second example shows how the constructive formula engine
certifies Hecke action independently of modular-symbol reconstruction.

All commands below are ordinary Sage-mode input.

## 1. Construct the space

Start with $S_2(\Gamma_0(23))$ and request enough coefficients to pass its
Sturm bound:

```sage
sage: S = CuspForms(23, 2, prec=12)
sage: S.dimension(), S.sturm_bound()
(2, 5)
```

The precision is an exclusive $O(q^{12})$ cutoff, so it contains every
coefficient needed by the Sturm theorem and several independent checks beyond
it.

## 2. Separate old and new directions

```sage
sage: O = S.old_subspace()
sage: N = S.new_subspace()
sage: O.dimension(), N.dimension()
(0, 2)
sage: N.q_expansion_basis_certificate(prec=12).verify()
True
```

At prime level $23$ there are no lower-level cusp forms contributing old
directions, so the entire two-dimensional rational space is new. At composite
level the same API constructs and certifies all degeneracy images exactly.

## 3. Recover Galois packets

`newforms()` decomposes the rational Hecke module into simple constituents.
It returns one object per Galois orbit, not one object for every complex
embedding:

```sage
sage: packets = S.newforms(names="a")
sage: len(packets)
1
sage: f = packets[0]
sage: f.defining_polynomial()
x^2 + x - 1
sage: f.coefficient_field()
Number Field in a0 with defining polynomial x^2 + x - 1
sage: f.certificate().verify()
True
```

The coefficient field is exact. No numerical root of $x^2+x-1$ has been
chosen.

## 4. Compute the $q$-expansion

```sage
sage: f.q_expansion(12)
q + a0*q^2 + (-2*a0 - 1)*q^3 + (-a0 - 1)*q^4 + 2*a0*q^5 + (a0 - 2)*q^6 + (2*a0 + 2)*q^7 + (-2*a0 - 1)*q^8 + 2*q^9 + (-2*a0 + 2)*q^10 + (-2*a0 - 4)*q^11 + O(q^12)
sage: f[2], f[3], f[5]
(a0, -2*a0 - 1, 2*a0)
```

Coefficient access and the printed series use the same authenticated exact
Hecke constituent.

## 5. Hand exact coefficients to an L-series layer

```sage
sage: L = f.lseries_input(12)
sage: L
Exact L-series input with 12 coefficients for a weight 2 modular form of conductor 23
sage: L.conductor(), L.weight(), L.functional_equation_center()
(23, 2, 1)
sage: L.coefficients()
(1, a0, -2*a0 - 1, -a0 - 1, 2*a0, a0 - 2, 2*a0 + 2, -2*a0 - 1, 2, -2*a0 + 2, -2*a0 - 4, a0 + 3)
sage: L.verify()
True
```

`ModularFormLSeriesInput` is deliberately an exact arithmetic handoff. It
records $L(f,s)=\sum_{n\geq1}a_n n^{-s}$, the conductor, weight, character,
coefficient field, normalization, and a verified finite coefficient prefix.
It does not claim that a complex embedding, gamma factors, root number, or
analytic continuation has already been selected.

## 6. Independently certify a formula span and its Hecke action

The full space $S_2(\Gamma_0(22))$ is generated by certified formulas. Its
good-prime Hecke action alone sees one repeated anemic eigensystem, while the
bad-prime operator $U_2$ separates the packet:

```sage
sage: F = CuspForms(22, 2).formula_subspace(prec=8)
sage: F.dimension(), F.ambient_dimension(), F.verify()
(2, 2, True)
sage: F.hecke_matrix(3).charpoly()
x^2 + 2*x + 1
sage: [(V.dimension(), V.is_simple()) for V in F.decomposition(anemic=True)]
[(2, False)]
sage: F.hecke_matrix(2).charpoly()
x^2 + 2*x + 2
sage: [(V.dimension(), V.is_simple()) for V in F.decomposition(anemic=False)]
[(2, True)]
sage: g = F.eigenforms(names="b")[0]
sage: g.q_expansion(8)
q + b0*q^2 - q^3 + (-2*b0 - 2)*q^4 + q^5 - b0*q^6 - 2*q^7 + O(q^8)
sage: g.certificate().verify(), g.lseries_input(7).verify()
(True, True)
```

Here the formula engine replays certified construction trees at the precision
required for $T_n$, and modular symbols serve only as the independent ambient
certificate. If a formula span is not Hecke-stable, Sage.js returns an exact
escaping-image obstruction and refuses to manufacture a restriction matrix.

For the underlying algorithms and receipt format, see
[Exact modular-form $q$-expansion bases](modular-form-q-expansions.md).
