# M0 reference laboratory: September 12 follow-up

This follow-up to [the campaign record](general-class-unit-frontier.md) records
reference readiness and evidence recovery under the approved sixteen additional
aggregate active-agent M0 hours. It does **not** declare M0 complete, establish
general Sage.js competitiveness, or start an optimization campaign.

## What is established

The pinned PARI 2.15.4 and Hecke 0.40.0 adapters now retain every compact result
in repeated requests. Both passed the small full-request/proof-policy fixture
on `opt`. Exact runtime inventory before and after those checks was unchanged.
That inventory records provider bytes and source-modeled JLL preload edges;
it is not a claim to have observed every process mapping.

The original 90 unconditional reference cases have now completed in both
systems: 180 retained outputs, with matching exact class-number, class-invariant,
discriminant, signature and torsion summaries for each pair. PARI used
`bnfcertify(b, 0) == 1`; Hecke used its unconditional class/unit interfaces.
All original fields and roles were preserved. Independent custody review
reproduced the counts and hashes. This is successful execution under the
reference proof policies, **not detached independent proof of completeness**,
Sage.js completion, or an unconditional performance score.

## Repeated requests and an infrastructure failure

A 14-field rank-two subset, seven totally real cubics and seven mixed quartics,
was predeclared for both engines at 100 and 200 bits, with three fresh separate
sample requests per field: 168 sample slots. Inputs, caps, versions, thread
count, CPU affinity, request boundaries and exact source were pinned before
dispatch. All samples use the declared seed; separate requests are not a claim
of independent random streams or zero JIT work.

An earlier wave failed because FLINT's quadratic sieve creates
`/tmp/siqsXXXXXX`, ignoring `TMPDIR`, while the service made global `/tmp`
read-only. All failed/interrupted receipts and missing slots remain recorded;
the pending 610-second reservation was charged in full. The corrected wave
uses a private project-owned temporary-directory bind and binds the original
host timing-lock inode back into that namespace. It does not change mathematics,
runtime packages, caches, source, input choices or resource caps. Non-CAS probes
verified temporary-file creation and exclusion through the original host lock.

The corrected wave closed with **168 of 168 eligible samples**, no rejected or
missing samples, and complete exact-summary agreement. All four services exited
successfully, their cgroups were gone, the timing lock was free, and the runtime
inventory was byte-identical before and after. The closed cumulative CPU ledger
charged 107,337.8564 seconds (about 29.82 hours), with no pending reservation.
This covers only 14 of the 360 performance fields; 346 remain outside this wave.

The offline repeat reviewer checks retained members, exact transport request
hashes, source/runtime provenance, policies, caps and controls. Missing or
rejected samples stay in its denominator. Its sampling admission is not an
independent class/unit certificate, authentication of predeclaration chronology,
or a claim that PARI's approximate regulator and Hecke's enclosure provide the
same numerical guarantee. Coordinator custody supplies chronology separately.

## Stress identities and the remaining implementation priorities

The fixed stress preparation contains 90 presentations and 18 sentinels, ten
and two per degree respectively. Independent review checked the selection rules,
required signatures, nullable equation-index handling and preservation of
reserved candidates. Sentinel ordering uses coefficient height, not an invented
field-discriminant or runtime estimate. No Sage.js result was used to select them.

The new bounded order-only diagnostic computes reference orders, not class or
unit groups. Its exact checker verifies basis containment and multiplication
closure, trace discriminants, indices, signatures and integral unimodular
transition matrices. Those checks detect inconsistency but cannot prove
maximality: a strict suborder can satisfy them. Reference maximality claims and
independent replay are therefore explicitly separate. Raw output is published
before exact checking, preserving evidence if checking or cleanup fails.

The three-field runtime fixture passed six fresh reference processes, including
the index-two order for `x^2 + 4`. The subsequent frozen 38-presentation diagnostic
completed all 76 processes successfully. Exact offline consistency replay
reproduced all 38 paired checks, and both reference engines established maximality
for each presentation. Runtime inventories remained unchanged and all services
closed. This does not independently prove maximality or complete the additional
distinct-field and stress-cost admission gates; no class/unit computation was
performed by the order diagnostic. A root-lock preflight failure occurred before
any fixture service or CAS process started; it was retained and corrected by
running that preflight as the worker user, preserving the original lock inode.

The closed cumulative CPU ledger after these diagnostics is 110,987.8564 seconds
(about 30.83 hours), including full prepaid diagnostic caps with no refunds.
The separately timestamped active-effort checkpoint records 52.9 of 56 M0 hours
as of 20:23 UTC; it is not a claim that subsequent review consumes no effort.

The old pre-M1 Sage.js smoke baseline remains 28 capability gaps, 40 incomplete
computations, 14 timeouts, two OOMs and six request errors—zero complete public
class-and-unit requests out of 90. It is not a benchmark of current main or the
draft M1 context. Unit-coordinate functionality, shared relation processing,
and unexplained saturation/certification costs remain major implementation
priorities. Existing nested local profiles identify expensive partial-ideal
handling across cubic/quartic fields; long quintic context times have not yet
been fully attributed. Do not call these the three largest global measured
phases before that attribution exists.
