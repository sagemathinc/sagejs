This freezes **membership**, not a performance result or the complete M0
laboratory. The adopted full plan is
`agents/general-class-unit-competitive-plan.md`, SHA256
`aceadd86d81f796740e9fa1e02c5d1a57854453ecc0d1774f3f09bf2dcd14403`.

## Fixed inputs

[`coverage.jsonl`](../bench/class-unit-groups/general-frontier/corpus/frozen/coverage.jsonl)
contains 1,800 fields: 200 in each degree 2–10, split 120 development and 80
holdout. The 360 performance members remain nested within coverage, 24
development and 16 holdout per degree. All previously selected signature
quotas are preserved. These are exactly the completed panel98 witness's
identities and roles; packaging makes no replacement or new selection.

There are 1,752 LMFDB labels and 48 generated fields, including **89 fields
with unknown source class numbers**. Unknown values stay null, not zero.
Mathematical results are validation metadata, not algorithm inputs: the
request exporter passes only labels and ascending exact integer coefficients.
Dispatch must never depend on labels or membership.

All 360 performance fields have paired PARI/Hecke discovery observations:
152 exceed one second and 46 exceed ten seconds in the faster reference.
[`observations.jsonl`](../bench/class-unit-groups/general-frontier/corpus/frozen/observations.jsonl)
retains all 526 discovery identities, including 87 unpaired outcomes, unchanged
from the accepted reconciliation. Original attempts, raw outputs and errors
remain in the backed-up laboratory archive; the JSONL is an observation index,
not a substitute for those receipts.

The 90 smoke identities are development-only, ten per degree and covering all
34 signatures. Selection first takes the smallest absolute discriminant in
each signature, then fills each degree to ten in increasing absolute
discriminant order. Ties use the pinned seed's SHA256 ordering. It uses neither
Sage.js success nor performance. Smoke fields are routine functional checks;
the performance and stress panels carry the expensive workload requirements.

## Admission and proof boundaries

The existing selected same-discriminant checks found 2,954 nonisomorphic pairs
in 150 groups using exact PARI `nfisisom`. Different metadata buckets separate
the remaining fields assuming the recorded maximal-order discriminants and
signatures are correct. This is exact reference evidence, not a formal negative
isomorphism certificate or independent certification of every maximal order.

All 48 generated presentations have checked Eisenstein-at-two irreducibility,
exact Sturm signatures, discriminant formulas and basis determinant identities.
Their field discriminants come from matched PARI/Hecke maximal-order results.
Of them, 35 are development and 13 are holdout; those 13 came only from the
initial reference-discovery pool. All 32 explicitly development-only entries
remain development. Reference-only measurements are not algorithm development;
the final Sage.js holdouts must remain unexecuted until candidate freeze.
No historical exposure search or additional isomorphism work was introduced.

Class and unit completeness in reference observations is conditional on the
references' GRH policy. PARI's working-precision regulator approximation is not
Hecke's absolute-radius enclosure. Discovery used single samples rather than
the required repeat/batch protocol. For panel98, an apt process was observed
only after execution and its start time was unavailable: timing overlap is
unknown. **These costs do not qualify a clean-host matched performance claim.**

## Offline use and reproduction

```sh
node bench/class-unit-groups/general-frontier/corpus/frozen/freeze.cjs check
node --test bench/class-unit-groups/general-frontier/corpus/frozen/freeze.test.cjs
node bench/class-unit-groups/general-frontier/corpus/frozen/freeze.cjs requests smoke
```

The exporter also accepts `development` and `development-performance`. It does
not expose an unrestricted holdout mode. Reading the public JSON fixtures is
not an access-control violation; the restriction prevents an accidental batch
run from opening the final holdout.

To reproduce packaging from the retained laboratory evidence directory:

```sh
node bench/class-unit-groups/general-frontier/corpus/frozen/freeze.cjs build /path/to/build/general-frontier
```

Every consumed artifact is byte-pinned in `manifest.json`. The builder creates
missing generated files exclusively or byte-compares existing ones; it never
silently replaces a freeze. Normal CI validates the committed fixtures offline,
without a database, CAS, network, or local evidence archive. Full raw evidence
publication/custody remains a qualification deliverable; hashes alone are not
a claim that every source artifact is publicly retrievable today.

Remaining M0 work includes matched 100/200-bit complete-request baselines,
repeated/batched timing, the additional 90-field stress set, the 90-case
unconditional set, and the completed capability/phase report. These sets and
requests are not frozen by this membership milestone. Existing caps and
acceptance thresholds are unchanged; later failures remain failures rather
than grounds for quietly replacing frozen fields.
