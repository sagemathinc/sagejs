# Offline multilingual reference fixtures

These fixtures contain original Sage.js test inputs, independently computed
mathematical constants, and short factual API summaries. They do not contain
vendor binaries, scraped documentation, or copied MATLAB/Wolfram output.

Reference URLs record why each syntax adapter exists. The tests are completely
offline and never treat another system's success flag as numerical evidence.

`scalar-root-references.json` covers the P1 root vertical slice.
`catalog-references.json` records the public names and convention facts used by
the foundational P6 catalog and its explicit unsupported boundaries.
