Row 16 now has a genuine matched resident boundary. Sage.js authenticates the
prepared `nfinit` data, compiles and allocates the translated 351-argument root
outside timing, restores all 351 mutable/scalar inputs outside every sample,
and times only one native call. Its live output owners must report the exact
54-relation, 48-prime, class-number-27 `(3,3,3)` terminal state.

The independent PARI arm authenticates pristine PARI 2.17.4, constructs
`nfinit0` before `READY`, resets the PARI stack and RNG for every sample, and
times exactly `bnfinit0(nf,0)`. Both arms publish the same minimal flag-zero
class-and-unit projection. The checker also repeats the Sage resident call,
rejects a changed prepared field, and rejects a changed semantic result.

Run `node bench/pari-class-group-port/check_row16_phase6_matched_prepared_timing.cjs`.
Its one-off times are correctness diagnostics only; qualification still needs
the quiet-host alternating protocol.
