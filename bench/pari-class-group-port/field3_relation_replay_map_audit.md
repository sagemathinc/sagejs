# Field-3 exact relation replay and class map

## Scope and authority

This lane consumes the immutable live-owner capture for
`x^4 - 2000022*x - 2000042` and the exact integral-basis multiplication table
from the frozen initial-collector fixture. The inputs are authenticated by the
following SHA-256 digests:

- owner capture: `246bfe2af51c8be732308719773fc7d696f7dc1bf21958c91d96cd8fc448954c`;
- initial fixture: `81b9d3b237e781a697f0ae170554426b363ec2235297407be1deed38ebbbc6fe`.

The 48 streaming words published by `field3_full_owner_authority.py` are
integrity latches only. They are neither read nor treated as mathematical
authority here. There are no calls to PARI after the prepared boundary.

## Exact relation replay

`field3_relation_replay_map.py` decodes all 301 column-packed relation rows,
all 301 four-coordinate principal generators, and all 288 retained factor-base
ideal HNFs. In ordinary CPython it checks:

- every packet is in canonical column HNF and its absolute determinant equals
  its retained norm;
- every provenance triple is `[column + 1, 0, 0]`;
- all 86,688 relation cells use the authenticated orientation and all nonzero
  exponents lie in `1..7`;
- for every relation, the exact product of retained factor-base ideals equals
  the principal ideal generated by the retained four-coordinate element.

All 301 identities pass. The matrix has 1,703 nonzero entries and maximum row
support 11. Mutating one relation exponent, one principal-generator
coordinate, one packet-HNF cell, or one multiplication-table cell is rejected.

## Bounded full-lattice presentation

Calling the generic `extract_relation_presentation` directly on the complete
301-by-288 source matrix exceeded 7 GiB RSS before completing. That route was
terminated and must not be retried in this campaign: it violates the four-GiB
ceiling, even though the final mathematical output is small.

The bounded route first asks mature FLINT for the canonical row-HNF **without
a transform**. This is an exact compression of the same full source row
lattice, not a selected answer fixture. It produces 288 rows with 555 nonzero
entries. Passing that canonical basis to `RelationPresentation` then gives a
verified rank-288 presentation with invariant factors `[2, 2]` and order 4.
The focused run used about 5.9 seconds for the HNF and 35.9 seconds for the
presentation. Monitored aggregate process-tree RSS peaked at 2,813,056 KiB,
below the hard 4-GiB cutoff.

This presentation is full in the class-group sense: its 288 columns are all
factor-base generators and its row lattice is exactly the lattice generated by
all 301 authenticated relations. It deliberately stores the 288 canonical
basis rows instead of a resource-prohibitive 301-square source transform.

## Suffix alignment and an arbitrary ideal

The published suffix selected one-based packet indices 11 and 2. Their
standard ambient vectors have full-presentation coordinates `(0, 1)` and
`(1, 0)`. Thus the suffix-to-full matrix over `F_2` is

```text
[[0, 1],
 [1, 0]],
```

which is invertible and self-inverse. A singular alignment and a changed class
coordinate are both rejected.

The exact map receipt uses the nontrivial integral element
`beta = (1, 1, 0, 0)` and the first suffix packet `P_11`. It constructs

```text
I = P_11 * (beta)
```

by exact quartic ideal multiplication. The full class coordinate of `I` is
therefore `(0, 1)`, its suffix coordinate is `(1, 0)`, and the exact quotient
witness for `I / P_11` is `beta`. The checker independently reconstructs the
principal HNF `(beta)` and verifies the ideal equality; this is not merely a
coordinate assertion.

## Remaining transform gap

The bounded class presentation does **not** recover the raw-relation to
accepted-unit 301-by-13 transform. The missing 3,913 integers belong to the
`hnfspec`/`hnfadd` ancestry. They cannot be reconstructed from fingerprints or
from the canonical HNF basis alone. The direct generic source transform is the
route that exceeded 7 GiB; unit reconstruction therefore still needs a
specialized bounded transform/solve output or retention of that owner in the
live root.
