# Authentic `h=1` class-correspondence completion

## Result

The qualified computation for

```text
x^3 - 20018*x + 20034
```

now has an internal, upstream-assumed **class-correspondence-complete** witness.
This phrase is intentionally narrower than either a publicly certified class
group or a complete class-and-unit result.

The witness retains and cold-replays the entire 105,468-byte exact presentation
authority. It reconstructs all 66 ordered factor-base ideals, checks all 73
principal relations, reruns the relation/HNF path, verifies the bidirectional
active-presentation maps, and reruns the full Smith transformations. The Smith
diagonal is `I_8`, so the authenticated relation lattice spans the complete
free group on the selected factor-base ideals.

Consequently the represented group is exactly trivial:

```text
class number                 1
invariant factors            []
class generators             []
generator order witnesses    []
```

The empty generator and order-witness lists are not omissions. They are the
mathematically correct, vacuous data for a trivial group.

## Exact saturation versus the upstream assumption

There are two different notions of completeness here.

The following is now exact and independently replayable:

> Within the free abelian group generated by the 66 retained factor-base
> ideals, the 73 authenticated principal relations have index one.

Equivalently, every retained factor-base ideal class is zero. No analytic
estimate, floating regulator, or PARI trust is needed for that statement.

The following remains an explicit upstream assumption:

> The selected factor-base ideals generate the full ideal class group of the
> prepared maximal order.

For correspondence purposes we accept PARI 2.17.4's factor-bound, honesty, and
analytic-index policy—including its GRH-dependent and undocumented heuristic
choices—as authority for this global generation statement. Under that one
global assumption, the exact trivial presentation proves that the full class
group is trivial.

The payload records this distinction directly:

```text

```

## Why this is not public certification

Sage.js's public completion contract requires evidence rather than a trusted
upstream policy label. Promotion would still need, as applicable:

- certified prepared maximal-order authority;
- a proved conditional-GRH or unconditional factor-base generation theorem
  and bound for this exact field;
- the corresponding replayable global class-saturation record;
- completed proof-stage/theorem metadata expected by the public adapter; and
- for a class-and-unit result, rigorous regulator and unit-saturation evidence.

None of those records is invented here. The internal status is stored in a
separate schema and cannot be confused with `ClassUnitComputation.complete`.
