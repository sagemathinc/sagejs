# Row 6 Phase-6 prepared-kernel timing readiness

Row 6 has a complete authenticated fresh correspondence result but no resident
prepared-kernel timing graph. Factor-base and initial-relation roots execute in
separate bounded children. Gate C compiles native stages without exporting a
reusable resident bundle, and the terminal transaction runs post-1137,
ancestry, class, unit, and C7 work in five further isolated children. Immutable
stage-owner I/O and detached replay are also part of that transaction.

The executable audit authenticates the prepared authority and frozen aggregate
result, rejects a mutation, defines the eventual common semantic projection,
and fails closed when asked for a timing arm. It specifically forbids treating
the correctness transaction's wall time as comparable with resident PARI
`bnfinit0(nf,0)`.

```sh
node bench/pari-class-group-port/row6_phase6_prepared_timing_readiness_check.cjs
```

`--live-fresh` reruns correctness without timing it. The missing implementation
is a reusable root/Gate-C bundle plus native resident versions of all five
terminal stages, joined into one serialization-free prepared-NF graph.
