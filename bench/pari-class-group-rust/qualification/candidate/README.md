# Compact Rust presentation-certificate producer

This qualification-only Rust program consumes the closed
`prepared-cubic-class-unit-v2` evidence emitted by the row-6 diagnostic. It
independently reconstructs the sparse relation matrix and emits a smaller,
replayable subset containing:

- invariant factors and their product;
- every factor-base generator's row in the modular class map;
- sparse lifts of the standard cyclic generators and exact order witnesses;
- exactly `m - n` sparse integer dependencies, each replayed against the full
  relation matrix;
- a compact exact lattice-index certificate.

## Exact compact lattice-index certificate

Write the full `m x n` relation matrix as `R = [A; B]`, where `A` is the first
`n x n` nonsingular block and `B` contains the `s = m - n` surplus rows. The
small-surplus computation emits `s` dependency rows

```text
C = (-Z | Y),                 C R = 0,
```

where `Y` is square. The verifier checks the following facts independently:

1. `D = |det(A)|` is the exact determinant exported by the fraction-free
   factorization.
2. Every row of `C` replays to zero against `R`.
3. `K = |det(Y)|` is nonzero, so the dependency rows have rank `s`.
4. A finite list of exact `s x s` minors of `C` has gcd one. Since the gcd of
   *all* maximal minors is the index of `row(C)` in its saturation, this proves
   that `row(C)` is primitive. Exhibiting a subset with gcd one is sufficient;
   no maximal-minor enumeration is required.

The integral left kernel of `R` is primitive because it is the kernel of a map
to the torsion-free group `Z^n`, and it has rank `s`. Thus replay, rank `s`, and
primitivity imply that `row(C)` is the entire integral left kernel, not merely
a finite-index sublattice.

Projection of that kernel onto the final `s` coordinates is injective and has
image generated by the rows of `Y`. Therefore `K = |det(Y)|` is the index by
which the surplus rows enlarge `row(A)`, and

```text
[Z^n : row(R)] = D / K.
```

The certificate is closed only after checking `K > 0`, `D mod K = 0`, and
`D / K` equals the independently emitted group order. Replay plus the expected
number of dependencies is deliberately not accepted: `(2,-2)` replays against
two equal relation rows and has the expected rank, but it is index two in the
true kernel generated by `(1,-1)`.

Malformed, non-replaying, nonsaturated, or arithmetically inconsistent input
exits with status 1 and emits no certificate.

```sh
cargo run --release -- path/to/prepared-cubic-v2.json > compact.json
```

## Hash-bound Sage.js replay

The retained qualification receipt is
`row6-sagejs-compact-replay-receipt.json`. It binds the exact prepared and
certificate bytes, the independently replayed result, the verifier source,
and the measured verification budget. Reproduce it from the repository root
using the content-addressed `/tmp` artifacts named in that receipt:

```sh
sha256sum \
  /tmp/sagejs-row6-v2-fresh-r3.json \
  /tmp/sagejs-row6-compact-fresh-r3.json \
  bench/pari-class-group-rust/qualification/candidate/test_sagejs_compact_adapter.py
SAGEJS_ROW6_HASH_BOUND=1 \
SAGEJS_RUST_PREPARED_V2=/tmp/sagejs-row6-v2-fresh-r3.json \
SAGEJS_RUST_COMPACT_CERTIFICATE=/tmp/sagejs-row6-compact-fresh-r3.json \
node bin/sagejs --python \
  bench/pari-class-group-rust/qualification/candidate/test_sagejs_compact_adapter.py
```

The test refuses a hash mismatch, replays the complete compact proof without
using producer booleans as authority, and emits one canonical JSON result line.
