# Wasm class-group presentation candidate

This crate is the first nontrivial class-group computation executed through
the Sage.js Rust/Wasm browser ABI. It is deliberately a **candidate** and must
not be published as a complete class-group result.

For the request polynomial `x^3 - 8*x^2 - 30*x - 34`, the artifact performs
all of the following at runtime:

1. deserialize one closed request shape, verify its exact schema/proof values,
   and parse four bounded polynomial coefficients;
2. construct PARI-policy factor-base descriptors from the polynomial;
3. enumerate primitive algebraic integers in deterministic coefficient shells;
4. compute exact `i128` norms and factor them over the derived factor base;
5. refine rational factors to prime-ideal valuations;
6. retain independent relations and twenty surplus relations; and
7. compute checked `i128` Smith invariants of the presentation.

The build contains no relation list, class number, or expected invariant. The
checked-in browser vector's `expected` member is consumed only by the Node
test harness after the Wasm call; the browser passes only `request` to the
artifact. The run reaches radius 5, derives 8 factor-base generators, and
retains 28 relation rows after visiting 1,074 shell points (339 primitive
nonscalar points, 26 smooth norms, and 25 appended search relations).

## Scope and limitations

- The result status is `candidate`: full rank plus surplus relations is not a
  class-group completion proof.
- The current trial supports monic cubic equation orders and uses their power
  basis. The qualification polynomial's independently prepared integral basis
  is a unimodular change of that basis, but the artifact does not yet certify
  maximality for arbitrary input.
- Arithmetic is checked fixed-width `i128`, sufficient for this small trial.
  A general implementation needs the already-proven pinned-GMP Wasm route and
  an explicit overflow fallback.
- Rust's `wasm32-wasip1` standard-library reactor imports `environ_get` and
  `environ_sizes_get`. The qualification loader supplies a deterministic empty
  environment. This is recorded in every receipt and is not evidence that the
  unmodified production WASI host can load the artifact.
- This trial computes presentation invariants only. It does not construct
  generator ideals, discrete-log/principality maps, units, a regulator, or a
  saturation/completion certificate.

## Reproduce

```bash
cargo test --release \
  --manifest-path bench/pari-class-group-rust/qualification/wasm-class-group-candidate/Cargo.toml

WASM_ROOT=$(node packages/wasm-toolchain/scripts/toolchain.cjs path)
CARGO_TARGET_WASM32_WASIP1_LINKER="$WASM_ROOT/sdk/bin/wasm-ld" \
  cargo build --release --lib --target wasm32-wasip1 \
  --manifest-path bench/pari-class-group-rust/qualification/wasm-class-group-candidate/Cargo.toml

node bench/pari-class-group-rust/qualification/browser/run-browser.mjs \
  --engines chromium,firefox,webkit \
  --artifact bench/pari-class-group-rust/qualification/wasm-class-group-candidate/target/wasm32-wasip1/release/sagejs_rust_wasm_class_group_candidate.wasm \
  --vector bench/pari-class-group-rust/qualification/browser/class-number-6.vector.json \
  --output bench/pari-class-group-rust/qualification/wasm-class-group-candidate/build/browser-receipt.json
```

The representative receipt in [`receipt.json`](receipt.json) summarizes one
15-call-per-engine run. The ignored complete browser receipt is regenerated by
the command above.

The recorded artifact was linked with the prepared Sage.js toolchain whose
content-addressed lock digest is
`37d8d819fd533570e0b707d3101ab2944f6488c4b4452b2b0a1a9ea04366452c`.
Its WASI SDK is 33.0 and its `wasm-ld` reports LLVM 22.1.0. A clean link with
that prepared `wasm-ld` produced the recorded 218,491-byte artifact with SHA-256
`9f27b7283160a944e016b5701429fddd923b6aab069e9c01881c871b4776bab8`.
The size increase from the earlier 146,358-byte artifact is the cost of replacing
its substring parser with `serde`/`serde_json` closed-shape deserialization; it
is disclosed rather than hidden as benchmark noise.
