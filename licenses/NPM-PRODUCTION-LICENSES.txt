Sage.js production npm license corpus
==========================================

This conservative corpus is generated from `pnpm licenses list --prod` and
includes the license/notice files from every returned package. It can be a
superset of modules selected into a particular SEA bundle. Registry integrity
values in the companion JSON bind each entry to the installed package.
